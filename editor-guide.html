🎨 Инструкция по использованию редактора

Полное руководство по форматированию текста в блогах и проектах

📍 Где находится редактор?

  1. 1️⃣ Откройте /admin/admin.html
  2. 2️⃣ Войдите (логин: infadmin, пароль: infadmin123)
  3. 3️⃣ Нажмите "+ Пост" или "+ Проект"
  4. 4️⃣ Найдите раздел "📄 Описания"

🛠 Панель инструментов

▼ Заголовок B I U S 🎨 A▼ 🖍 ■▼ ≡ Список 🔗 Ссылка 🗑 Очистить

🔤 B - Жирный текст

Выделите текст → Нажмите B

Результат: Жирный текст

💬 I - Курсив

Выделите текст → Нажмите I

Результат: Курсивный текст

🎨 A▼ - Цвет текста

Выделите → Нажмите A▼ → Выберите цвет

Результат: Красный текст

🖍 ■▼ - Фон текста

Выделите → Нажмите ■▼ → Выберите цвет

Результат: Выделенный текст

📏 Заголовки H1, H2, H3

Выделите → Нажмите ▼ → Выберите размер

H1 - Большой
H2 - Средний
H3 - Маленький

📋 ≡ - Списки

Выделите → Нажмите ≡ → Выберите тип

  • Пункт списка 1
  • Пункт списка 2

🔗 Ссылка

Выделите текст → Нажмите 🔗 → Вставьте URL

Результат: Кликабельная ссылка

🗑 Очистить форматирование

Выделите → Нажмите 🗑

Убирает все форматирование

📝 Пример создания блога

Шаг 1: Напишите заголовок

Напишите: "Как увеличить продажи с помощью блогеров"

Выделите → Нажмите "▼ Заголовок" → Выберите "Heading 1"

Шаг 2: Добавьте введение

Напишите первый абзац с описанием

Для абзацев просто нажимайте Enter

Шаг 3: Выделите важное

Выделите ключевые слова:

  • Выделите слово → Нажмите B (жирный)
  • Или измените цвет → Нажмите 🎨 A▼

Шаг 4: Добавьте список

Создайте список преимуществ:

  1. Напишите 3-5 пунктов построчно
  2. Выделите все строки
  3. Нажмите кнопку ≡ → Выберите нумерованный или маркированный

Шаг 5: Сохраните

Нажмите кнопку "💾 Сохранить" внизу формы

✨ Ваш блог с форматированием готов!

💡 Полезные советы

  • ✅ Используйте заголовки для структуры текста
  • ✅ Выделяйте важное жирным шрифтом
  • ✅ Используйте списки для перечислений
  • ✅ Цветной текст привлекает внимание (не переборщите!)
  • ✅ Делайте абзацы — так легче читать
  • ✅ Проверяйте как выглядит на странице блога
